# Gerador de legenda

Ferramenta web para converter a legenda `.SRT` de voos de drone DJI, cruzar as coordenadas com a base de estacas da ferrovia e gerar:

- nova legenda `.SRT` com km, pacote, segmento, cidade, corte/aterro, OAE, PN, superestrutura (elemento, extensão, raio e superelevação), pátios e AMV;
- vídeo com a legenda gravada, mini-mapa, logos e balões nas estacas redondas;
- vídeos sem legenda calibrados pelo km inicial, km final e pontos de referência;
- vários vídeos em sequência juntados numa legenda e num vídeo únicos.

A base de estacas da FICO (BD estacas, versão de 02/10/2026, km 000+000 a 269+000, superestrutura até o km 364+778) já vem embutida na página. A legenda, o vídeo e os logos de quem usa são processados no próprio navegador e não são enviados para nenhum servidor.

Use Google Chrome ou Microsoft Edge atualizados.
