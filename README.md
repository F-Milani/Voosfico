# Gerador de legenda Drone DJI

Ferramenta web para converter a legenda `.SRT` de voos de drone DJI, cruzar as coordenadas com a base de estacas da ferrovia e gerar:

- nova legenda `.SRT` com km, pacote, segmento, cidade, corte/aterro, OAE, PN e superestrutura;
- vídeo com a legenda gravada, mini-mapa, logos e balões nas estacas redondas;
- tabela `.csv` com a estaca de cada quadro.

Todos os arquivos (legenda, base de estacas, vídeo e logos) são processados no próprio navegador e não são enviados para nenhum servidor.

Use Google Chrome ou Microsoft Edge atualizados.
